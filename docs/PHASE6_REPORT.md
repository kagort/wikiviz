## По этапам

### Этап 1. Воспроизводимые фикстуры
- `WikipediaClient.fetch_article` принимает необязательный `revision_id`. Он сообщает об ошибке, если ревизии нет или она относится к другой статье.
- Манифест `frontend/tests/fixtures/real/manifest.json` хранит адрес, ревизию и имя файла. Обычный запуск `export_fixtures` берёт закреплённые ревизии, `--update` берёт текущие и записывает их номера.
- Добавлены Julius Caesar (en) и Сократ (ru). Три старые фикстуры после перехода на ревизии совпали с прежними байт в байт.

### Этап 2. Исправления по визуальной проверке
- **2.1, лишние заголовки France:** не дефект. Разведка (`scripts/inspect_headings.py`) показала, что `Economy`, `Government` и `Culture` — настоящие подразделы `External links`, а не заголовки навигационных блоков. В данных они правильно вложены. Ни в одной из пяти статей нет заголовков внутри navbox.
- **2.2, сноски `[107]`:** убраны из ячеек и шапок таблиц, из `caption` таблиц и подписей картинок. Проверка вынесена в общий модуль `app/extractors/text_utils.py`. Обычный `<sup>` (км²) сохраняется.
- **2.3, код, разбитый пробелами:** подсветка синтаксиса делит выражение на много `<span>`. Теперь текст внутри одного `<code>` склеивается как есть, а между разными элементами пробел остаётся (`True False`).

### Этап 3. Диагностика
- **Картинки:** все 32 адреса из фикстур отвечают. Превью всегда отвечают 200. Крупные версии изредка отвечают 429: это ограничение частоты у Wikimedia, повтор проходит. Как проверить у себя: F12 → Network → фильтр `wikimedia`, посмотреть код ответа.
- **Символ `×`:** это кнопка закрытия подсказки на карте Leaflet. Она видна в тексте страницы, только пока подсказка открыта. Не наш дефект.

### Этап 4. TimelineWidget
- Сначала исправлены данные. Даты «день месяц год» с маркером до н. э. (BC, BCE, «до н. э.», «до Р. Х.») теперь сохраняются только годом (`-0044`), по ТЗ §16.2. Раньше они молча становились годами н. э. Служебные разделы исключаются вместе со всеми подразделами: France «External links → Culture», Цезарь «Sources → Secondary sources», Сократ «Литература → Статьи».
- Виджет (вариант А, решение владельца) — вертикальный список по возрастанию даты, показывается при двух событиях и больше. Даты подписаны по языку статьи («44 BC», «469 до н. э.», «14 марта 1879»). Рядом указаны источник и уверенность. Некорректная дата не роняет виджет: такое событие показывается как есть в конце.

### Этап 5. InfoBoxWidget
- Контракт (вариант Б, решение владельца): `InfoboxField` получил необязательное поле `group`, синхронно в Pydantic и TypeScript.
- `app/extractors/infobox_extractor.py` разбирает первый `table.infobox`.
  - Группы задают строки-заголовки. Строки с «•» относятся к открытому заголовку или к предыдущей строке без «•» («GDP (PPP)» → «Total»).
  - Ключи уникальны: `area_total`, `population_density_2`.
  - Убираются сноски, скрытый текст и `.noprint` (иначе «35 years ago» меняло бы фикстуру каждый день).
  - Списки и `<br>` в значениях склеиваются через запятую, а в подписях `<br>` превращается в пробел.
- Виджет показывает пары «название — значение» в порядке строк инфобокса и подзаголовки групп.

### Этап 6. StatisticsChart
- Вариант А (решение владельца): горизонтальные столбики без библиотеки, без новых зависимостей.
- Группа годится для диаграммы, если в ней не меньше трёх значений с общим началом подписи и все в «%». Из пяти статей это только религии France.
- Только столбики, не круг: проценты вложенные (Christianity 48% включает Catholicism 43%), сумма больше 100%.
- Диаграмма свёрстана как таблица «подпись | столбик | значение»: это и табличный вид для доступности. Подсказка при наведении сделана через `title`.

### Этап 7. Шапка таблиц и примечания
- Контракт (вариант Б, решение владельца): `Table` получил поле `notes`.
- Строка `<td>` во всю ширину над настоящей шапкой становится названием таблицы, а если подпись уже есть — примечанием. Многострочная шапка собирается с учётом `colspan`/`rowspan` («Возраст — до 15»). Строки во всю ширину под данными («Источник: …») уходят в `notes`. `TableWidgetView` показывает примечания под таблицей.
- Изменились только две таблицы Токио. Таблицы Python и Цезаря не изменились.
- Тест «таблица без названия» переведён на таблицу сражений Цезаря: у таблицы населения Токио теперь есть название.

## Найденные ловушки

1. **Гипотезы о разметке надо проверять.** Версия «лишние заголовки — это navbox» не подтвердилась: это была настоящая структура статьи.
2. **Даты до н. э. в тексте молча становились датами н. э.** Извлекатель видел «15 March 44» и не смотрел, что идёт после года.
3. **У служебного раздела есть подразделы с обычными названиями** («Culture» внутри «External links»). Исключать нужно по вложенности, а не по названию.
4. **Подсветка синтаксиса дробит код на `<span>`.** Склейка «через пробел» портит код, а склейка «впритык» портит соседние значения. Граница проходит по элементу `<code>`.
5. **`.noprint` содержит значения, вычисляемые при каждом запросе** («35 years ago»). Без исключения фикстура менялась бы ежедневно.
6. **`<br>` значит разное в подписи и в значении:** в подписи это перенос строки, в значении — перечисление.
7. **`<th colspan>` над шапкой — заголовок группы колонок, а `<td colspan>` — пояснение.** Строки, которые начинаются с `<th>`, бывают данными (сражения Цезаря).
8. **JavaScript переставляет ключи объекта из одних цифр в начало.** Поэтому ключи инфобокса никогда не состоят из одних цифр.
9. **На чистой копии `tsc` падает, пока не выполнена сборка:** Next.js создаёт тип `LayoutProps` во время `npm run build`. Порядок проверок на новой машине: сначала `npm run build`, потом `tsc`.
10. **Сертификат прокси в облачной среде.** `WikipediaClient` намеренно использует `trust_env=False` (из-за VPN у владельца) и поэтому не видит сертификат прокси облачной среды. Скрипты там запускались через временную обёртку, которая не попала в репозиторий. Код клиента не менялся.

## Оставшийся техдолг

- **Закреплённая ревизия не закрепляет шаблоны и Wikidata.** Пример: «Stable release» у Python берётся из Wikidata в текущем виде и изменится с выходом новой версии Python. Тесты не зависят от конкретных значений.
- **`rowspan` в строках данных не раскрывается** (сражения Цезаря: «Gallic Wars» на 12 строк). Такие строки короче остальных (ТЗ §12.4).
- **Даты из текста:**
  - вступление русской статьи подписано английским «Introduction»;
  - одна дата в разных разделах даёт несколько событий (Токио, 10 марта 1945);
  - даты до н. э. одного года в одном разделе сливаются в одно событие.
- **Даты из инфобокса:** для должности со сроком «64–44 BC» берётся конец срока (Pontifex maximus — 44 BC).
- **Шум в `numbers`** (не чистился по ТЗ): группа «GDP (nominal)» захватывает Gini, Time zone, Calling code; у годов единицы «BC» и «до». StatisticsChart их отфильтровывает.
- **Инфобокс:**
  - строки во всю ширину без заголовка (France: Motto, Anthem) не извлекаются;
  - берётся только первый инфобокс (у Токио их два);
  - вложенные таблицы в значениях сплющиваются через запятую (Цезарь, «Office»).
- **BOM в 12 файлах** (`.gitignore`, `README.md`, 5 файлов извлекателей, 5 файлов тестов). Сейчас он ничему не мешает.
- **Защита dev-страниц** — Phase 10. В облачной среде не грузится подложка карты OpenStreetMap: это сетевые правила среды, не код.
